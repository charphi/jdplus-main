Hodrick–Prescott Filter

The HP filter decomposes any time series into a smooth trend and a short-term cycle component. Adjust λ to control smoothness — a higher λ penalises trend curvature more, producing a flatter trend and a larger cycle. This page calls POST /hello/hodrickPrescott live.

📚 Lesson 1: Introduction to Time Series

A time series is a sequence of data points indexed in time order. Examples include daily stock prices, monthly unemployment rates, quarterly GDP figures, or yearly population counts.

💡 Key Concept

Time series data has three essential components: observations (the values), time periods (when each value was measured), and frequency (how often measurements occur).

Common Frequencies
  • FREQ_YEARLY – Annual data (e.g., yearly inflation)
  • FREQ_QUARTERLY – Every 3 months (e.g., GDP reports)
  • FREQ_MONTHLY – Monthly measurements (e.g., employment)
  • FREQ_DAILY – Daily observations (e.g., stock prices)
Example: Time Series Structure
{
  "id": "gdp_series",
  "series": {
    "start": {
      "frequency": "FREQ_QUARTERLY",
      "year": 2020,
      "pos": 0
    },
    "values": [100.5, 102.3, 101.8, 104.2]
  }
}

This represents quarterly GDP data starting from Q1 2020. The pos field indicates the position within the year (0 = Q1, 1 = Q2, etc.).

📊 Lesson 2: Descriptive Statistics

Before analyzing a time series, we typically compute descriptive statistics to understand its basic properties: central tendency (mean), spread (standard deviation), and distribution (quartiles).

The Statistics Endpoint

The POST /hello/statistics endpoint calculates:

  • n – number of observations
  • average – arithmetic mean
  • stdev – standard deviation
  • min/max – range of values
  • q25, q50, q75 – quartiles (25th, 50th, 75th percentiles)

📏 Lesson 3: Normalization (Standardization)


      

        

          Normalization (also called standardization) transforms data so it has
          a mean of 0 and standard deviation of 1. This is useful for comparing series with different
          scales or units.
        


        
The Formula

        
normalized_value = (original_value - mean) / stdev


        

          For example, if your series has mean = 100 and stdev = 10, a value of 110 becomes:
          (110 - 100) / 10 = 1.0

🔄 Lesson 4: Time Series Transformations


      

        

          Time series transformations help us analyze changes and trends. Two fundamental operations are:
        


        
1. Percentage Change (Pct)

        

          Calculates the relative change between periods:
          (y[t] / y[t-lag] - 1) × 100
        

        

          For example, if a value grows from 100 to 105, the percentage change is:
          (105 / 100 - 1) × 100 = 5%
        


        
2. Difference (Delta)

        

          Calculates the absolute change: y[t] - y[t-lag]
        

        

          For example, if a value grows from 100 to 105, the difference is: 105 - 100 = 5

📈 Lesson 5: Hodrick-Prescott Filter


      

        

          The Hodrick-Prescott (HP) filter separates a time series into two components:
        

        
    
          
  • Trend – the smooth long-term movement
    • 
          
  • Cycle/Noise – short-term fluctuations around the trend
    • 
        


        

          The smoothness of the trend is controlled by parameter λ (lambda):
        

        
    
          
  • Small λ (e.g., 100) → trend follows data closely
    • 
          
  • Large λ (e.g., 14,400) → trend is very smooth
    • 
        


        

          💡 Common λ values
          

            • Annual data: λ = 100

            • Quarterly data: λ = 1,600

            • Monthly data: λ = 14,400
